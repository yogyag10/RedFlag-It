# RedFlag

A Chrome extension and local FastAPI service that checks rental listings on Facebook Marketplace, Craigslist and Furnished Finder for scam warning signs. It points out red flags to verify; it does not decide whether a listing is fraudulent.

## What it does

- Open a listing and a traffic light appears in the corner:
  - 🟢 **No red flags**
  - 🟡 **Check first**: one red flag
  - 🔴 **High risk**: two or more red flags
- **See details** lists only the checks the listing failed (for example deposit demand, personal info request, payment sent abroad).
- Search result cards get a quick text-only badge.
- The last five checks are saved on your device.

## Run it

**1. Start the backend**

```sh
cd backend
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Check `http://127.0.0.1:8000/health` shows `"fraud_model": "ready"`.

**2. Load the extension**

1. Go to `chrome://extensions` and turn on **Developer mode**.
2. Click **Load unpacked** and choose the `extension` folder.
3. Open a rental listing and click the RedFlag bubble.

After code changes, restart Uvicorn (backend) or click reload on RedFlag in `chrome://extensions` and reload the tab (extension).

**Optional:** `requirements-vision.txt` enables photo checks with a local OpenCLIP model. `RENTSHIELD_DATABASE_URL` enables PostgreSQL/PostGIS listing history for price and photo-reuse comparisons. `RENTSHIELD_API_KEY` requires a bearer token.

## How it works

**NLP.** Five spaCy detectors (`backend/housing_fraud_nlp`) look for the RCMP's rental scam warning signs. They use grammar, not just keywords: "send a $500 deposit to hold it" is flagged, "the deposit is due at lease signing" is not. Countries are found with named-entity recognition and only flagged when tied to a payment.

**Model.** Six one-question decision trees (`backend/ml`), each checking one behaviour:

| Tree | Behaviour |
|---|---|
| `model_deposit_demand` | asked to send a deposit to reserve the unit |
| `model_personal_info_request` | asked for ID, SIN, banking info or a verification code |
| `model_etransfer_request` | asked to pay by e-transfer or wire |
| `model_high_demand_claim` | "lots of interest", "won't last" pressure |
| `model_foreign_payment` | money sent outside Canada |
| `model_price` | rent lower than similar listings |

Two or more trees voting fake means red. A low price only counts alongside another red flag. The older rule-based score (0–100) is still shown as a secondary line.

**Data.** 500 labelled listings (400 real, 100 scams): 20 real Vancouver Marketplace listings, 5 hand-written scams, and 475 generated by `ml/generate_data2.py`. Real and fake listings share style, neighbourhoods and prices, so only scam behaviour tells them apart.

**Results** (5-fold cross-validation): balanced accuracy 0.855, precision 1.00, recall 0.71. Tested on unseen hand-labelled listings, it caught 5 of 5 scams and flagged 0 of 20 real listings.

Retrain after changing the data:

```sh
cd backend
.venv/bin/python -m ml.generate_data2       # rebuild ml/data2.json
.venv/bin/python -m ml.fraud_bagging_model  # retrain and save the model
```

## API

- `POST /api/analyze`: full check for one listing. Returns `risk_light` (`green`/`yellow`/`red`), `fake`, `votes`, `trees` (one `"vote | code | rule"` per tree), `consensus_rules`, plus the rule score, evidence signals and photo results.
- `POST /api/quick-scores`: text-only scores for up to 20 search cards.
- `GET /health`: service, database, vision and model status.

```json
{
  "fake": true,
  "votes": { "fake": 2, "real": 4, "unknown": 0 },
  "risk_light": { "color": "red", "warnings": 2, "label": "2+ warning signs: high risk" },
  "consensus_rules": ["personal info request warning sign detected", "price <= 1862.5 (this listing: 1700)"],
  "trees": [
    "real | model_deposit_demand | no deposit demand warning sign",
    "fake | model_personal_info_request | personal info request warning sign detected",
    "real | model_etransfer_request | no e-transfer request warning sign",
    "real | model_high_demand_claim | no high demand claim warning sign",
    "real | model_foreign_payment | no foreign payment warning sign",
    "fake | model_price | price <= 1862.5 (this listing: 1700)"
  ]
}
```

## Privacy

- Only listings you open are checked; there is no crawler. No cookies, seller names or account data are sent.
- Listings are processed in memory unless you configure a database, which stores only minimal features (price, coordinates, image hashes), never listing text or contact details.
- All models run locally; nothing is sent to OpenAI or another AI API.
- The training data includes the text of 20 public Marketplace listings, with one advertiser's name and phone number redacted.

## Limits

Extraction depends on each site's page layout and can miss details. The model is trained mostly on generated data and can be wrong; rooms and studios can look "cheap" next to full apartments. Always verify the address, the unit, who is renting it and where your money is going before you pay.
